# Financial_Data_Analysis - 금융데이터분석 2차 과제
## <과제 간단 요약 및 접근방법>
#### 참고: 데이터는 교수님께서 제공해주신 것을 사용함. 

### 1. 데이터셋 만들기

   -> 주어진 데이터를 이용해 수익률을 계산 후 

   -> NSShock의 기준을 세운 뒤 데이터 병합

### 2. Event Study 디자인

   -> 주어진 공식을 통해 알파와 베타를 측정한 뒤, 
   
   -> 이를 토대로  AR (Abnormal returns)을 구하고,

   -> AR을 통하여 CAR (Cumulative Abnormal Returns) 계산
   
### 3. 통화정책 충격에 따른 회귀분석

   -> 2번에서 구한 값과 주어진 회귀식을 통해 베타를 추정 후 결과 해석

### 4. 비교 분석

   -> 경제적으로 의미있는 국가 특성 변수 중 하나를 선택하여 (작성자는 '자본시장 개방도'를 선택)

   -> 주어진 회귀식을 통해 결과 도출 후 해석 및 분석
